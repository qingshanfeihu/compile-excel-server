# 术语表

大致按使用流程排列。括号里是代码、命令或配置里用的写法。

| 术语 | 含义 |
|---|---|
| 编译助手（compile-excel） | 用户电脑上的编程助手加上 compile-excel 技能，负责把脑图编译成用例、同步数据、上机 |
| 服务端（compile-excel-server，命令 `ces`） | 本仓库：账号登录、分发编译数据、检索手册 |
| 管理菜单 | 运行 `ces` 不带参数时出现的编号菜单 |
| 数据目录 | 服务端存放账号、编译数据、手册、证书、审计日志的目录，默认 `~/ces-data` |
| 连接串 | 管理员发给用户的一行地址，形如 `https://主机:8900#ca=指纹`；`ces link` 显示 |
| 内置 CA | 服务端自己生成的证书签发机构，用来给服务端和网关签发 https 证书 |
| 证书指纹（`#ca=`） | 内置 CA 证书的 SHA-256，用户靠它确认连上的是真正的服务端 |
| 访问码 | 管理员建账号时生成、交给用户的登录口令，只显示一次 |
| 设备码 | 登录时编译助手显示的 8 位字母，用户在授权页核对 |
| 授权页（`/activate`） | 用户在浏览器里填用户名和访问码的页面 |
| 令牌 | 登录成功后服务端发给编译助手的凭证，分访问令牌（15 分钟）和刷新令牌（7 天） |
| 权限（scope） | 令牌能做哪些事，例如下载编译数据、在跳板机上跑用例；见 [安全设计](security.md#权限) |
| 服务客户端 | 不是人、而是程序用的账号：网关和发布器各有一个，用客户端密钥登录 |
| 客户端密钥 | 服务客户端的口令，只显示一次，建议存成权限 600 的文件 |
| 构建（构建号，`device_build`） | 设备 `show version` 里的执行构建名；编译数据按构建分开发布 |
| 包（bundle） | 某个构建的一组编译数据文件，编号由文件清单算出 |
| 通道 | 每个构建有 `candidate`（待发布）和 `stable`（用户默认同步）两个通道，各指向一个包 |
| 发布 | 把 `candidate` 上的包切到 `stable` |
| 回滚 | 把 `stable` 切回以前的某个包 |
| 数据类别（kind） | 包里文件的类别：命令树、投影、手册、规格书、Excel 模板、测试框架、回填记录 |
| 命令树（`cmdtree`） | 设备命令的结构定义，客户端据此判断命令是否存在 |
| 投影（`projections`） | 从命令树、框架等数据派生出的规则与表格，例如领域文法 `domain_grammar.json` |
| 旧版工件 | 早期按文件名下载的接口（`/v1/artifacts/*`），现在由 `stable` 包派生 |
| 发布器 | 把编译数据上传到服务端的工具（`tools/import_infotest.py`、`tools/publish_data_dir.py`） |
| InfoTest | 原来的测试集成平台；编译数据最初由它的批入口（收敛链）生成 |
| 跳板机 | 能连到被测设备的那台机器，测试框架装在上面 |
| 网关（cexg） | 装在跳板机上的服务，把上机操作变成需要登录的工具 |
| 床 | 一套被测设备加上它们所在的跳板机环境 |
| 租约 | 用一张床之前先租下来，同一时间只有一个人能用 |
| 审计日志 | 记录登录、管理操作的日志，每行带上一行的哈希，改动或删除会被发现 |
| 判据代码（vendor） | 网关上机前检查用的代码，从 compile-excel-skills 同步而来，放在 `gateway/vendor/` |
